# WEANJ — Why Enzyme And Not JAX

Side-by-side Enzyme.jl, Reactant.jl and JAX implementations of programs whose efficient
form is irregular: particle cell lists, sequential sweeps, data-dependent compaction, and
convergence-tested solvers. Each example checks that all three tools compute the same
gradient and times them on a CUDA GPU.

**Site:** https://michel2323.github.io/WEANJ

## Run it locally

```bash
make setup          # Julia 1.12 env, Python/JAX env (needs juliaup, uv, quarto)
quarto preview      # browse and re-run notebooks
make run-gpu        # re-execute everything on an idle GPU
```

See [setup](setup.qmd) for details.

## Layout

| Path | Contents |
|---|---|
| `examples/NN-name/` | `index.qmd` (page) embedding `enzyme.qmd`, `reactant.qmd`, `jax.qmd` |
| `julia/` | Julia environment and shared helpers (`WEANJ` module) |
| `python/` | Python environment and shared helpers (`weanj` package) |
| `data/` | Shared inputs, generated by Julia |
| `benchmarks/` | Timing results and correctness-check gradients written by the notebooks |
| `_freeze/` | Executed notebook outputs (committed; CI renders from these without a GPU) |
| `AGENTS.md` | Plan and progress tracking |
